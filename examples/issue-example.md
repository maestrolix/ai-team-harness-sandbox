# Отметка личной задачи как выполненной

## Цель

Пользователь может отметить свою задачу как выполненную и видеть сохранённый результат при повторном открытии списка.

## Границы

- Допущение: пользователь уже вошёл в систему.
- В рамках задачи: завершение собственной задачи, запрет изменения чужих задач, повторное завершение и сохранение состояния.
- Вне рамок: вход в систему, создание и удаление задач, изменение их содержания и возврат в невыполненное состояние.

## Сценарии

1. **Своя задача.** У Анны есть невыполненная задача «Купить молоко». Анна отмечает её как выполненную. Ожидаемый результат: задача Анны становится выполненной.
2. **Чужая задача.** Анна пытается отметить задачу Бориса как выполненную. Ожидаемый результат: изменение запрещено, задача Бориса сохраняет прежнее состояние.
3. **Повторное завершение.** Анна повторно отмечает свою выполненную задачу как выполненную. Ожидаемый результат: задача остаётся выполненной, дополнительных изменений или побочных эффектов нет.
4. **Повторное открытие.** Анна закрывает и снова открывает список после завершения своей задачи. Ожидаемый результат: задача отображается выполненной.

## Критерии приёмки

- [ ] Пользователь может отметить собственную невыполненную задачу как выполненную.
- [ ] Пользователь не может изменить состояние чужой задачи.
- [ ] Повторное завершение выполненной задачи не меняет результат и не вызывает побочных эффектов.
- [ ] После повторного открытия списка завершённая задача остаётся выполненной.
