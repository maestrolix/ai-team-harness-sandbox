# Отметка личной задачи как выполненной

## Цель

Пользователь может завершить свою задачу и увидеть сохранённый результат при повторном открытии списка.

## Границы

Пользователь уже вошёл в систему. Меняем только завершение существующей задачи.
Вход в систему, создание, удаление, редактирование и возврат задачи в невыполненное состояние — вне задачи.

## Сценарии и критерии приёмки

- [ ] Анна завершает свою невыполненную задачу — она становится выполненной.
- [ ] Анна пытается завершить задачу Бориса — получает отказ, состояние задачи не меняется.
- [ ] Анна повторно завершает свою выполненную задачу — результат сохраняется, побочных эффектов нет.
- [ ] Анна заново открывает список — завершённая задача остаётся выполненной.
