Первая попытка остановилась по лимиту модели 240 секунд до публикации: локальная правка
сохранена, событие стало Blocked. После сохранения этой правки отдельным patch и возврата
тестового файла к исходной версии выполнен явный `--retry` с тестовым лимитом 360 секунд.
Повтор прошёл за **152,3 секунды**; суммарно две попытки — **6 минут 45 секунд**.
До повтора убраны служебные поля GitHub из prompt: 46 552 → 7 852 символа с сохранением
текста, авторов, ссылок, строк, diff и обсуждений. Штатные лимиты конфигурации не увеличены.

Оба оркестратора и три специалиста использовали **gpt-6.1-sol / high** — подтверждено
`turn_context` всех пяти сессий. В тестовой ветке QA и wrapper выполнили 34 теста;
35-й тест сохранности компактного контекста отдельно прошёл в исходной ветке и её CI.

**Ограничение живого прогона:** новые соединения GitHub CLI периодически завершались TCP timeout.
Для этого теста HTTP-вызовы `gh api` заменены во временной обвязке одним постоянным HTTPS-соединением
к настоящему GitHub; авторизация получена из GitHub CLI. Модель, Git, очередь, проверки,
commit/push и обработка результатов работали реально. Это не подтверждает стабильность
штатного транспорта `gh` на данной машине; сам каркас ради обхода сети не изменялся.

До этой доработки человек уже слил PR #1 и #3. Новая работа выполнена отдельной веткой;
во время этих тестов `main` сохранилась на `0491ece3fc67faed2c4853157cbe012d3de69968`.
Автослияний и постоянного наблюдателя нет. Go/React-приложение этим тестом не проверялось.

Два ограничения среды:

  требуется другой тариф либо публичный репозиторий. Защита `main` на сервере не включена.
- Вложенный sandbox Codex в Docker блокируется настройками user namespaces.
  Полные прогоны выполнены локальным Codex CLI; Docker проверен до чтения GitHub включительно.

Результат — рабочий минимальный каркас с этими явными ограничениями, без автослияния
и без запущенного в фоне постоянного наблюдателя. Команды настройки и восстановления — в README.
